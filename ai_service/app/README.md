# PDF/Document RAG AI Service

This project is a **Retrieval-Augmented Generation (RAG)** AI service that allows you to:

1. Extract text from PDFs, DOCX, PPTX, or images (OCR-supported).  
2. Chunk the extracted text into manageable pieces.  
3. Embed the chunks using a **multilingual embedding model** for semantic search.  
4. Store the embeddings in a **vector database (FAISS)** for fast retrieval.  
5. Generate clear, concise answers to user queries using a **local LLM (Ollama / Mistral)** based on retrieved chunks.

---

## ⚙️ Requirements

### 1️⃣ Python

- Python **3.9 or higher**

### 2️⃣ Python Dependencies

Install dependencies using:

```bash
pip install -r requirements.txt
````

### 3️⃣ System Dependencies (IMPORTANT)

#### 🔹 Tesseract OCR

OCR is required for scanned PDFs and images inside documents.

**Windows:**

Download from:
[https://github.com/UB-Mannheim/tesseract/wiki](https://github.com/UB-Mannheim/tesseract/wiki)

Default install path:

```text
C:\Program Files\Tesseract-OCR\tesseract.exe
```

Make sure this path is correctly set in the code.

#### 🔹 Ollama Local LLM

1. Download and install Ollama: [https://ollama.com](https://ollama.com)
2. Pull the model (e.g., Mistral):

```bash
ollama pull mistral
```

3. Make sure the Ollama service is running locally:

```bash
ollama run mistral
```

The API will be available at: `http://localhost:11434/api/generate`

---

## ▶️ Running the AI Service

Start the FastAPI server:

```bash
uvicorn app.main:app --reload
```

The service will be available at:

```text
http://localhost:8000
```

## 📝 API Endpoints

### 1. Extract & Chunk File

**POST** `/extract/`
Payload:

```json
{
  "file_id": "file123",
  "file_path": "path/to/file.pdf",
  "file_type": "pdf"
}
```

Returns: Chunks of text from the document.

### 2. Extract, Chunk & Embed File

**POST** `/extract/embed`
Payload same as above.

Returns: Chunks with embeddings stored in FAISS for similarity search.

### 3. Query Vector Store

**POST** `/extract/query`
Payload:

```json
{
  "query": "What is a Career?",
  "top_k": 5
}
```

Returns: Top `k` chunks most similar to your query, plus a **concise answer generated by the LLM**.

## 🧰 Project Components

* **Text Extraction**: `pymupdf`, `python-docx`, `python-pptx`, `pdf2image`, `pytesseract`, `Pillow`
* **Embeddings**: `sentence-transformers`, `torch`
* **Vector Store**: `faiss`, `numpy`
* **LLM**: `Ollama` with `Mistral` (local)
* **Web API**: `FastAPI`, `Uvicorn`, `Pydantic`
